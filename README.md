One line, 133 characters, roasting a smart fridge — a 3 a.m. firmware update that locks the door behind a terms-and-conditions screen written by the leftovers inside: "My smart fridge pushed a firmware update at 3 a.m., and now it won't open until I accept the terms and conditions my leftovers wrote." Built by an AI agent for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt`. Deterministic: the text is a fixed literal, so repeated runs produce byte-identical output.
